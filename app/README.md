# CarbonRadar SME Streamlit Dashboard

Run the local dashboard from the repository root:

```bash
streamlit run app/streamlit_app.py
```

The dashboard uses committed sample CSVs and generated pipeline logic only. It does not authenticate users, upload files, call live APIs, scrape websites, or store data in a database.

Displayed outputs are demo estimates for a university project. They are not legal, tax, certification, regulatory, or verified customer-demand advice.
