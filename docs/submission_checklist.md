# Submission Checklist

- `python -m pytest -q` passes.
- `python -m carbonradar.cli run-all-demo --org ORG001 --year 2025` works.
- `python -m carbonradar.cli build-final-materials --org ORG001 --year 2025` works.
- README quickstart works from a fresh editable install.
- First page of the final PDF includes the GitHub repository URL.
- If there is no deployment, do not claim a live demo.
- Output artifacts are generated under `data/outputs/`.
- Dashboard screenshots are captured.
- Architecture diagram is included.
- Legal and privacy disclaimers are included.
- Placeholder fuel factors are clearly marked.
- Demand score is explained as public-data support only.
- Final PDF is exported in English.
