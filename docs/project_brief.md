# CarbonRadar SME Project Brief

## One-line pitch

CarbonRadar SME helps Taiwanese SME manufacturers turn electricity bills, fuel records, and supplier questionnaires into Scope 1/2 emissions estimates, carbon-fee scenarios, and supplier disclosure readiness reports.

## Target customer

Primary users:

- Taiwanese SME manufacturers with 20–200 employees
- Metal processing factories
- CNC machining factories
- Plastic injection factories
- Electronics component suppliers

Typical buyer or user:

- factory owner
- operations manager
- plant manager
- QA / ISO / ESG contact person
- finance or admin staff responsible for customer questionnaires

## Problem

Small and medium-sized manufacturers often receive carbon-related requests from customers but lack dedicated ESG teams. Their electricity, fuel, production, and supplier questionnaire data are scattered across accounting, operations, procurement, and QA teams.

The goal is not to replace certified ISO 14064 verification. The goal is to provide a low-cost pre-audit tool that helps SMEs organize data, estimate exposure, and prepare customer-facing reports.

## MVP scope

v0.1 should support:

- sample organization master data
- sample electricity bills
- sample fuel logs
- sample supplier disclosure records
- emission factor table
- validation
- Scope 1 calculation
- Scope 2 calculation
- carbon-fee scenario simulation
- supplier disclosure readiness scoring
- Markdown report generation
- CLI commands
- tests

## Out of scope for v0.1

- frontend dashboard
- live deployment
- PDF rendering
- OCR
- government API ingestion
- full Scope 3
- CBAM product-level calculation
- ISO certification workflow
