# References and Research Notes

## Taiwan carbon fee assumptions

For v0.1, use the following scenario parameters:

- annual emissions threshold: 25,000 tCO2e
- standard rate: NT$300 / tCO2e
- preferential rate A: NT$50 / tCO2e
- preferential rate B: NT$100 / tCO2e

The system must clearly state that this is a scenario estimate, not a legal or tax determination.

## Electricity emission factor

For demo calculations, use:

- 2025 electricity emission factor: 0.467 kgCO2e / kWh

Keep factor year, source name, source URL, and notes in the data model.
